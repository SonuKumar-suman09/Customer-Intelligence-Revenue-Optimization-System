# Customer Intelligence & Revenue Optimization System

## Overview
This project is a "real-world Data Science application" that demonstrates how customer data can be analyzed to support **marketing strategy, revenue prediction, and customer retention decisions**.

The solution follows an **end-to-end data science workflow**, combining unsupervised and supervised machine learning techniques with clear, business-focused visualizations.

---

## Business Problems Addressed
- Identification of **high-value customers** for targeted decision-making  
- Segmentation of customers into **meaningful and actionable personas**  
- Prediction of **customer spending behavior** using regression models  
- Detection of **churn-risk customers** using classification techniques  
- Presentation of insights through **executive-ready visual analytics**

---

## Techniques & Tools
- **Programming Language:** Python  
- **Libraries:** Pandas, NumPy, Scikit-learn  
- **Machine Learning Techniques:**  
  - PCA (Dimensionality Reduction)  
  - K-Means Clustering  
  - Linear Regression  
  - Logistic Regression  
- **Visualization:** Matplotlib, Seaborn  

---

## Dataset
**Mall Customer Segmentation Dataset**

Key features used:
- Age  
- Annual Income (k$)  
- Spending Score (1–100)  

The dataset is used as a **representative sample of retail customer data** commonly seen in analytics use cases.

---

## Project Workflow
Data Loading
→ Data Scaling
→ PCA (Dimensionality Reduction)
→ Customer Segmentation (Clustering)
→ Spending Prediction (Regression)
→ Churn Prediction (Classification)
→ Business Visualization


---

## Key Visual Outputs
- PCA-based customer segmentation map  
- Income vs Spending customer value matrix  
- Customer segment distribution  
- Regression performance (Actual vs Predicted)  
- Customer churn distribution  
- Customer segment behavior heatmap  

All visualizations are designed to be clear, interpretable, and business-oriented**.


## Model Evaluation
- **Clustering:** Silhouette Score, Davies–Bouldin Index  
- **Regression:** R² Score, RMSE  
- **Classification:** Precision, Recall, F1-Score  

Evaluation metrics were selected based on industry-standard practices**.
